# PWA design baseline

> Только `pwa/**`. Админка и backend этот стиль не применяют.

**Главный референс (целевой язык):** `pwa/design/reference/light-shipment-baseline.png` + `light-shipment-baseline.md`.

Исторические: `home-baseline.md` (тёмный hero), `profile-baseline.md`, `auth-baseline.md` — не брать для новой вёрстки, если они спорят со светлым макетом.

Токены: `pwa/design/tokens.css`. Акцент целевого макета — **песочно-золотой / amber**, не cyan.

## Язык (обязательно для новой UI)

- Светлый warm off-white фон, белые мягкие карточки, крупные скругления, много воздуха.
- Нет тёмного hero на главной.
- Акцент: тёплый gold/sand для CTA, статусов «в пути», графика, линии на карте.
- Заголовки почти чёрные; мета — серые.
- Кнопки-иконки круглые, touch ≥ 44px.
- Bottom nav: **плавающая чёрная капсула**, круглые пункты, активный — светлый круг; без подписей.
- Тема `dark` на `<html>` остаётся, но базовая композиция — светлая, как на макете.

## Экраны макета → Делег

- Home (аватар, приветствие, поиск, KPI, график) → главная заказов.
- Create Shipment (адреса, пакет, CTA) → создание заказа.
- Tracking (карта, таймлайн, Call/Chat pills) → выполнение / наблюдение.

Новые экраны повторяют этот макет, а не invent с нуля.
