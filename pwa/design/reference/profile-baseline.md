# Profile Baseline (базовый дизайн экрана профиля)

> Область: только PWA (`pwa/**/*.{vue,css,ts}`). Админка (`admin/**`) и backend этот дизайн не применяют.

Референс: макет profile-экрана (светлая версия; дополняет `profile-baseline.png`).

## Композиция
- Фон страницы `--color-surface-muted` (#f4f4f5), весь контент — на светлой поверхности.
- Верхняя панель: круглая icon-button «назад» слева, заголовок `Profile` по центру, icon-button «…» справа.
- Ниже — блок пользователя, затем список настроек, внизу — кнопка выхода.

## Блок пользователя
- Слева круглый аватар (~96px) с **акцентной дугой-кольцом** (оранжевый border, неполная дуга).
- Справа: имя — первая строка regular («David»), вторая bold («Brandon ✋») с эмодзи-акцентом; `text-2xl/3xl`.
- Под именем: слева тонкая вертикальная черта (акцентная), блок `Joined` (muted, xs) / `10 days ago` (semibold, primary).

## Список настроек (card rows)
Каждая строка — отдельная белая карточка (`rounded-2xl`, border subtle, вертикальный gap между строками, без divider-линий):
- слева — **квадратный тёмный контейнер** (`rounded-xl`, ~44×44) с белой пиктограммой (Orders — куб, Payments — карта, Account — пользователь);
- label (`text-sm`, primary);
- справа — светлый круг (`surface-muted`) с тонким шевроном `>`.

## Кнопка выхода
- Внизу, во всю ширину контента: **чёрная pill-кнопка** (`rounded-full`, ~52px высоты) с иконкой выхода слева и белым лейблом «Sign Out»; hover — слегка светлее.

## Типографика
- Заголовок экрана: `text-base font-semibold` по центру.
- Имя: `text-2xl` (вторая строка `font-bold`).
- `Joined`: `text-xs text-text-secondary`; значение: `text-sm font-semibold`.
- Labels строк: `text-sm`.

## Адаптация под Jober
| Референс | Jober |
|----------|-------|
| Аватар с акцентной дугой | Аватар пользователя в hero профиля |
| Joined 10 days ago | «В системе N дней» (по `created_at`) |
| Orders / Payments / Account | Мои заказы, Платежи (позже), Настройки аккаунта |
| Sign Out (чёрная pill) | Выход из аккаунта |
