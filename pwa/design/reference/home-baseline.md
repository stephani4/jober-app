# Home Baseline (базовый дизайн главного экрана)

> Область: только PWA (`pwa/**/*.{vue,css,ts}`). Админка (`admin/**`) и backend этот дизайн не применяют.

Референс: макет home-экрана (пользователь зафиксировал его как базовый дизайн приложения).

## Композиция
- Контраст двух зон: **тёмный hero** (верхняя треть) + **светлое тело** страницы.
- Hero прижат к верху, нижние углы скруглены (`rounded-b-3xl`); тело — белый фон.
- Внизу — фиксированный bottom bar с 5 пунктами.

## Hero (тёмная зона)
| Элемент | Описание |
|---|---|
| Фон | `--color-surface-hero` (#141414), лёгкая текстура из тонких диагональных линий (opacity ~4%) |
| Верхняя панель | круглый аватар слева; справа круглая кнопка-колокольчик (white/10, иконка) с оранжевой точкой-индикатором в правом верхнем углу |
| Приветствие | `Hello,` (regular, белый) на первой строке, `Brandon! 👋` (bold + эмодзи-акцент) на второй; `text-2xl/3xl` |
| Поисковая строка | белая pill: иконка лупы слева (muted), placeholder «Track your parcel»; справа внутри строки — отдельная круглая кнопка-сканер (белый круг с иконкой, небольшой отступ) |
| Быстрые действия | 2 кнопки в ряд (grid-cols-2): белые `rounded-2xl` с тенью; слева квадратный `rounded-xl` акцентный контейнер с белой иконкой, далее label («Send parcel», «Track order») |

## Тело (светлая зона)
- Заголовок секции: `Active delivery` — `text-lg font-semibold`, слева.
- **Карточка доставки** (белая, `rounded-2xl`, `shadow-card`, padding ~16px):
  - слева — изображение товара в круглой подложке;
  - заголовок: `ID: 70D200B` (semibold) + серый pill-статус `Transit` справа от ID;
  - название товара (semibold) под ID;
  - справа — декоративная иллюстрация (груз/коробки).
  - **Таймлайн статуса** под шапкой карточки: закрашенный акцентный круг с галочкой → акцентная линия → чёрный pill-лейбл шага («Sent») → акцентный полый круг → конечная точка; под таймлайном маршрут `📍 Dubai → To → ⏱ Ajman` (иконки + muted-текст).
  - Карточки идут вертикально с gap ~12px.

## Bottom navigation
- Белый бар, 5 пунктов, под иконками мелкие подписи.
- Активный таб — **крупный акцентный круг** (оранжевый, белый icon) с тенью, приподнят над баром; подпись чёрная.
- Неактивные: тонкие контурные иконки, muted-подписи, без заливки.

## Типографика
- Приветствие: `text-2xl font-semibold` (вторая строка bold).
- Заголовки секций: `text-lg font-semibold`.
- ID заказа: `text-sm font-semibold`; название: `text-sm font-semibold`; метаданные: `text-xs text-text-secondary`.

## Адаптация под Jober
| Референс | Jober |
|----------|-------|
| Hello, Brandon! | Приветствие исполнителя/заказчика в hero (`AppHeroHeader`) |
| Track your parcel | Поиск по заказам/исполнителям |
| Send parcel / Track order | «Создать заказ» / «Найти заказ» (quick actions) |
| Active delivery + таймлайн | «Активный заказ»: точки маршрута = шаги таймлайна (точка → маршрут) |
| Пинь-статус Transit | Статус заказа (`wait`/`process`/`confirmation`) |
| Bottom tabs | Заказы, Поиск, создание (центральный акцентный круг), Отклики, Профиль |
