# Auth Baseline (базовый дизайн экранов входа/регистрации)

> Область: только PWA (`pwa/**/*.{vue,css,ts}`). Админка (`admin/**`) и backend этот дизайн не применяют.

Референс: скриншот двухпанельного auth-экрана (пользователь зафиксировал его как базовый дизайн приложения).

## Сетка (≥ 1024px, `lg`)
- Экран разделён на две части: `grid lg:grid-cols-2`.
- **Слева** — белая карточка с формой (логотип, заголовок, подзаголовок, pill-инпуты, cyan-кнопка, разделитель «или»), под ней карточка «Присоединяйтесь к 20k+».
- **Справа** — градиентная панель с крупным заголовком сверху и стеклянной карточкой со слайдером плюсов внизу.
- На мобильных (< 1024px) правая панель скрыта, остаётся форма.

## Поверхности и цвета
| Элемент | Цвет |
|---|---|
| Фон страницы | `--color-surface-muted` (#f4f4f5) |
| Карточка формы | `--color-surface-card` (#ffffff), радиус `--radius-hero` (1.75rem) |
| Кнопка действия | `--color-accent-cyan` (#00b5d8), hover `--color-accent-cyan-hover` |
| Рамка pill-инпута | `--color-border-input` (#cfe3ea), focus cyan + ring |
| Градиент правой панели | from `--color-hero-grad-from` (#9ed2e4) to `--color-hero-grad-to` (#5ea8c8) |
| Заголовок на панели | `--color-hero-heading` (#294c57) |
| Стеклянная карточка | white/25 + `backdrop-blur`, радиус `--radius-hero` |

## Типографика
- Логотип «Jober»: `text-lg font-semibold`.
- Заголовок формы: `text-3xl font-semibold tracking-tight`.
- Подзаголовок: `text-text-secondary`.
- Заголовок на панели: `text-3xl–4xl font-semibold leading-snug`, ограничен по ширине.

## Компоненты
- **Pill-инпут**: `rounded-full`, иконка слева (абсолютное позиционирование), без внешних лейблов (sr-only для a11y).
- **Pill-кнопка**: `rounded-full bg-accent-cyan py-3.5 text-white`.
- **Разделитель**: тонкие линии + «или» по центру.
- **Join-карточка**: белая pill-карточка, кластер аватаров (цветные кружки с инициалами), жирный текст «Присоединяйтесь к 20 000+ пользователей!», серый сабтекст, круглая кнопка-стрелка.
- **Слайдер**: PrimeVue Carousel, слайд = pill с названием плюса + описание, стеклянная карточка, автопрокрутка 5s, circular.
