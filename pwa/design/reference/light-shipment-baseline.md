# Light shipment baseline (целевой UI PWA)

> Область: только PWA. Админка и backend этот макет не применяют.
> Картинка: `pwa/design/reference/light-shipment-baseline.png` (три экрана: home, create, tracking).
> Это **актуальный визуальный язык**. Исторический тёмный hero (`home-baseline.md`) не использовать для новой вёрстки.

Бренд: **Делег**. Акцент макета — тёплый песочно-золотой, не яркий `#f97316`.

## Язык

- Фон приложения: тёплый off-white / cream (`~#F4F3EF`), не чистый белый.
- Карточки: белые или слегка теплее фона, крупные радиусы (`rounded-2xl` / `rounded-3xl`), мягкая тень, много воздуха.
- Текст: почти чёрный для заголовков, серый для меток.
- Акцент: песочный / amber-gold (кнопки, chart bars, статус «в пути», линия маршрута на карте).
- Иконки: тонкий outline, круглые контейнеры.
- Никакой тёмной hero-шапки на главной.

## Экран 1 — Home

- Светлый фон на всю высоту.
- Слева: круглый аватар + две строки (`Good Morning` muted / имя semibold + эмодзи).
- Справа: светлый pill «Chat» и круглая кнопка колокольчика с красной точкой.
- Крупный заголовок в 2 строки (`Today's Shipment Status Update.`).
- Поиск: светло-серая pill, лупа слева, **чёрная круглая** кнопка справа внутри строки.
- Секция `Shipment Overview` + текстовая ссылка `See all`.
- Две KPI-карточки в ряд: иконка в скруглённом квадрате, период-dropdown (`Today`), крупная цифра, мини-тренд.
- Блок `Weekly shipment Overview` + бежевый bar chart.
- **Bottom nav**: плавающая **чёрная капсула** (`rounded-full`) над низом экрана, 4 круглых пункта; активный — светлый круг с тёмной иконкой, остальные — тёмные круги со светлыми иконками. Без подписей под иконками.

## Экран 2 — Create (создание заказа)

- Светлый фон, назад слева, заголовок по центру.
- Блоки `Pickup Address` / `Delivery Address`: pin в круге, адрес, лёгкая карточка.
- `Package Information`: поля Weight / Size / Package Type как card-rows.
- `Select Courier`.
- Низ: `Total Cost` слева, справа широкая **золотая pill** CTA (`Book Shipment`).

## Экран 3 — Tracking (выполнение / наблюдение)

- Карта сверху (изометрия/город), линия маршрута акцентом, пины A/B.
- Круглые белые кнопки на карте: назад слева, more справа.
- Заголовок заказа `#ID`, город muted, справа золотой pill-статус (`In Transit`).
- Вертикальный таймлайн: закрашенные тёмные точки (готово) → текущий шаг с акцентом → полые точки (ожидание); справа дата/время и локация.
- Две pill-кнопки внизу: заполненная золотая (`Call Driver`) + обводка золотом (`Chat Support`).

## Соответствие Делег

| Макет | Делег |
|---|---|
| Home / Shipment Overview | Главная заказов |
| Create Shipment | Создание заказа (точки, тариф) |
| Shipment Tracking + таймлайн | Выполнение / наблюдение |
| Chat / Call Driver | Чат заказа, связь с исполнителем |
| Bottom capsule | `AppBottomNav`: Заказы, поиск/отклики, создание, профиль |
